# 海大電機學程島 EE ISLAND

國立臺灣海洋大學電機工程學系的互動式學程網頁（課堂作業）。版面參考 [HEART 政策島](https://puma.taipei/heart-island)。

**線上瀏覽：** https://kevin001610.github.io/ntou-ee-island/

## 內容

- **學年島**：大一到大四四座島，用橋相連。每棟房子是一門課，左半邊是上學期、右半邊是下學期。
- **小人**：每座島上有一位學生在走動，點他就能看到那一年的課表。
- **系主任**：站在電機系館島上。點他會開始導覽，依序介紹共同課程、四個學年、六大領域、碩士班選修和輔系。
- **銜接線**：橘色虛線連接分好幾個學期修的課，例如電子學二上 → 二下 → 三上。
- **六大領域島**：通訊與訊號處理、控制、固態電子、電力與電子電路、電波、資訊科技，各自連到碩士班的專業選修課。
- **輔系港**：輔系必修科目和代碼。
- 另外有右側索引和搜尋、四年課表清單、白天／夜晚切換，地圖可以拖曳和縮放。

## 資料來源

電機系「大學部必修與核心課程關聯圖」（兩個版本）、「碩士班選修課程關聯圖」（三份）、「輔系必修科目表」。實際開課與修業規定以系上當年度公告為準。
